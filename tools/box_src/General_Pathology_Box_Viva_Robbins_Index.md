## How to read this file

- ⭐ = number of times the question appeared across all boxes (⭐ = once, ⭐⭐⭐ = three times). Stars = exact repetition count.
- **Box tags** show where each occurrence came from, e.g. `A-1 Q13, Q15`. A-5 and A-6 have no printed question numbers, so only the box is given (`A-6 ×2` = appeared twice in that box).
- Compound questions are split into single questions. Questions that repeat with only a wording change are merged into one line, and every box they came from is listed.
- 🖍️ = this question was highlighted in yellow on your scan.
- Chapter order follows Robbins. Topics that Robbins does not cover directly (fluid and electrolytes, blood transfusion, body-fluid examination, and so on) sit under the nearest Robbins chapter.
- Clinical-scenario questions are grouped at the end of each chapter. Scenarios with different wording but the same ask are merged, and each box's original wording is shown in brackets.
